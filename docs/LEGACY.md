# 原基础版已统一归入标准版

原 STT 2026.03.12 · 基础版 不再作为独立下载选项；请使用 [STT 2026.10.31.2 · 标准版](https://github.com/chonger1209/stt_new/releases/tag/v2026.10.31.2)。标准版保留原有桌面功能，以及后续的后台保存、单实例、计时、格子和可靠性改进，不含千问管理。

## 升级并保留设置和记录

先从旧STT自身入口正常退出，并备份整个旧目录。用标准版EXE替换旧程序，保留自己的 config.txt、screen_time_history.db、time_stream_history.db，不用公共默认配置覆盖个人设置，不同时运行两版。

标准版源码位于 standard/，不是仓库根目录的旧单文件脚本；根目录旧脚本与旧EXE已从当前分支移除。旧基础版的Release和标签撤下，提交历史保留，撤下前的发布资料及附件已由维护者离线备份。

需要千问管理时，另选 [千问增强版](https://github.com/chonger1209/stt_new/releases/tag/v2026.10.24)。
