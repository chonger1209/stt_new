# 旧版 STT 2.0 使用说明

[返回仓库首页](../README.md) · [旧版下载](https://github.com/chonger1209/stt_new/releases/tag/stt_new) · [新版完整手册](../optimized/README.md)

## 版本身份

旧 Release 名称为 **2.0**，标签为 **`stt_new`**，发布说明记录的版本日期为 **2026.03.12**。名称、标签、日期属于不同信息，不要与新版 `v2026.10.22` 混淆。

旧版发布记录、原下载附件和标签保留。仓库根目录 `stt_new.py`、`dist/stt_new.exe` 也保留旧版文件。

## 基本功能

- Caps Lock ON/OFF 状态与红绿背景。
- 按软件名称/窗口标题关键词自动切换 Caps Lock。
- 前台应用时长统计及彩色时间流。
- 倒计时和开始、暂停、重置控件。
- 悬浮、置顶、拖动、自动隐藏标题栏和右键菜单。
- 配置文件、两份 SQLite 历史数据库和日志。

旧版没有新版增加的千问管理、数据库专用后台队列或数据目录单实例保护。新版时间流累计修复、倒计时边界修复和配置升级策略也不能反推为旧版已具备。

## 下载与操作

1. 从旧版发布页下载 `stt_new.exe`，放在可写目录。
2. 首次运行后检查配置与数据文件实际创建位置；旧版使用相对路径的部分行为与新版不同，建议保持固定启动目录。
3. 鼠标移入窗口/靠近上沿显示标题栏，统计按钮查看当天时长，设置按钮打开配置。
4. 修改配置后使用刷新入口；需要保留旧版行为时，先备份文件再修改。
5. 使用程序自己的关闭入口正常退出，避免未保存区间丢失。

旧版原发布说明主要涉及布局优化，并未证明所有计时与参数边界已修复。需要准确的新版累计规则与失败保存机制时，请使用新版。

## 配置和数据

常用字段包含配色、窗口大小/位置、置顶、软件列表、每格秒数、统计刷新和倒计时时长。旧版默认值与具体生效行为以旧源码和旧发布说明为准，不直接套用新版默认值表。

保留 `config.txt`、`screen_time_history.db`、`time_stream_history.db`。这两份数据库分别承载时长与时间流相关记录，不建议只迁移其中一份。

## 升级或回退

升级前退出旧版并复制整个目录作为备份，替换新版程序/图标，保留自己的配置和数据库。不要直接把新版便携包内的默认配置覆盖到旧设置上。

回退前备份最新数据，再换回旧 EXE。不要用升级前的数据库覆盖升级后新增的记录。旧版没有新版实例锁，避免同时运行两版处理同目录数据。
