# STT · 屏幕时间与 Caps Lock 助手

Windows常驻桌面工具：Caps Lock状态、按软件自动切换大小写、前台应用时长、彩色时间流和番茄倒计时。

## 标准版第一次使用

1. 下载 STT-2026.10.31.1-standard-windows-x64-portable.zip，完整解压到可写目录。
2. 运行stt_new.exe，不需要安装Python、模型或管理工具包。
3. 设置或右键菜单打开config.txt；保存后刷新。
4. 正常退出会保存统计和窗口坐标；Esc是退出，不是最小化。

配置、两份SQLite数据库和logs目录缺失时自动生成。标准版保留背景色、自动大小写、应用统计、时间流、倒计时、置顶、拖动和统计菜单。未配置的进程默认记录，隐藏规则只影响对应视图。

## 为什么提供新的标准版

卸载本地模型不应迫使用户退回旧程序。标准版保留增强版已经完成的后台写入、失败保留pending、两库共同事务、正常退出保存、清醒计时、跨午夜、单实例、格子累计、缓存、低权限进程识别、日志轮转和配置保存修复，只移除模型管理部分。

## 升级

先正常退出旧STT，备份整个旧目录。替换EXE时保留自己的config.txt、screen_time_history.db、time_stream_history.db，不用公共默认配置覆盖个人设置，不同时运行新旧版。标准版兼容现有数据库，忽略千问字段；它不会卸载模型、停止独立服务或删除计划任务。

千问增强版需要额外的Strata、模型环境、工具包配置与任务注册；详见[独立服务配置](optimized/docs/INDEPENDENT_SERVICE.md)。不用千问管理无需下载增强版。
