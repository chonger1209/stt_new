# 新版配置手册

[返回使用手册](../README.md)

## 配置在哪里、怎么生效

实际读取的是 EXE 同目录的 `config.txt`。源码运行时读取 `stt_new.py` 同目录的文件。`config.default.txt` 是参考模板，不是第二份生效配置。

1. 点击标题栏 `⚙` 或右键“设置”。
2. 在文本编辑器里修改并保存，保持 UTF-8 编码。
3. 回到 STT 点 `⟳` 或右键“刷新”。

`#` 开头的整行是注释。值后的分号 `;` 表示行内注释，显示名称和软件关键词中不要放分号。不要在颜色值后追加 `# 注释`，因为颜色本身就以 `#` 开头。

**全局配置必须放在第一个 `[进程名]` 之前。** 某字段看似不生效时，先检查它是否被放进了进程配置节。

## 全部 13 项全局配置

| 字段 | 默认值 | 含义与生效行为 |
|---|---|---|
| `color_caps_on` | `#fa6666` | Caps Lock 开启时背景色。支持 Tk 可识别颜色，建议 `#RRGGBB` |
| `color_caps_off` | `#4CAF50` | Caps Lock 关闭时背景色 |
| `color_titlebar` | `#2c3e50` | 标题栏及千问按钮等相关控件的背景色 |
| `window_width` | `300` | 窗口宽度，像素、正整数；不会按比例缩放字体 |
| `window_height` | `240` | 统计面板收起时的窗口基准高度，像素、正整数 |
| `window_x` | `-1` | 窗口横坐标，正常退出时自动更新 |
| `window_y` | `-1` | 窗口纵坐标，正常退出时自动更新；横纵任一为 `-1` 时按居中处理 |
| `always_on_top` | `true` | 是否始终置顶，建议仅填 `true` 或 `false` |
| `software_list` | `CAXA,CAD,SOLIDWORKS` | 自动开启大写锁定的软件/标题关键词，英文逗号分隔、忽略大小写 |
| `grid_second_per_block` | `30` | 每个时间流格子代表的秒数，也是定时采样/时间流更新间隔，正整数 |
| `screen_time_refresh_frequency` | `10` | 统计刷新次数/10 秒，正整数；当前最快每秒一次 |
| `timer_duration_minutes` | `25` | 番茄倒计时分钟数，正整数 |
| `qwen_idle_timeout_minutes` | `120` | 千问连续闲置多久后卸载模型，分钟、正整数；需兼容千问环境 |

无效颜色由界面检查后回退默认色。整数格式错误或应为正数却小于等于 0 时回退默认值，并记录原因。布尔值请按表填写；不要把“不认识的文字”当作一种受支持的开关值。

## 常见修改示例

### 一分钟一格、每 5 秒更新统计、倒计时 45 分钟

```ini
grid_second_per_block = 60
screen_time_refresh_frequency = 2
timer_duration_minutes = 45
```

统计刷新换算：`10` 每秒一次，`2` 每 5 秒一次，`1` 每 10 秒一次；大于 `10` 当前也不会快于每秒一次。它不改变每约 200 毫秒识别前台窗口的频率。

每格秒数改变后，会按当天已有区间重新计算格子，不会修改数据库时长。因此把 30 改成 60 后，格子数量通常会减少。

### 修改自动大小写软件列表

```ini
software_list = CAXA,CAD,SOLIDWORKS,MyEditor
```

在前台窗口切换时，应用显示名或标题包含任一关键词则开启 Caps Lock，其他窗口关闭。子串匹配可能命中比你预期更多的窗口，建议使用有辨识度的关键词。

```ini
software_list =
```

留空表示切换到所有软件时都关闭 Caps Lock，**不是关闭自动切换功能**。当前没有独立的“停用自动大小写”配置项。

### 千问闲置两小时休眠

```ini
qwen_idle_timeout_minutes = 120
```

这控制卸载模型，不是退出接收服务、关闭电脑或系统睡眠。将 `120` 改成 `180` 就是三小时；提醒按钮同步显示对应时长。不要用 `0` 代表永不休眠，`0` 会回退默认 120。

### 恢复窗口位置

```ini
window_x = -1
window_y = -1
```

保存后刷新即可按居中逻辑定位。正常退出会再次保存实际坐标，所以不必期望 `-1` 永远留在文件里。多显示器坐标与屏幕布局有关；移除显示器后窗口找不到时先恢复居中。

## 进程规则：显示名称和两个独立开关

进程规则写在全局设置之后，每个程序独立一节：

```ini
[msedge.exe]
display_name = Microsoft Edge
show_in_screen_time = true
show_in_time_stream = true

[LockApp.exe]
display_name = Lock Screen
show_in_screen_time = false
show_in_time_stream = true

[Example.exe]
display_name = 示例程序
show_in_screen_time = true
show_in_time_stream = false
```

| 字段 | 省略时 | 含义 |
|---|---|---|
| 节名 `[进程名.exe]` | 必填 | 匹配进程文件名，忽略大小写 |
| `display_name` | 节名 | 界面和新记录使用的名称 |
| `show_in_screen_time` | `true` | 是否出现在当天柱状统计 |
| `show_in_time_stream` | `true` | 是否参与可见时间流格子的累计和显示 |

**没有配置的程序也正常记录，两个视图默认都显示。** 这不是软件白名单。

`false` 不停止记录、不删除历史。比如 LockApp 统计为 false、时间流为 true，是两个视图各自的选择，不冲突。

程序记录的是显示名称。两个进程使用同一显示名称时会合并；视图隐藏判断也会受到同名规则影响。建议不同程序使用不同名称，尤其不要给同名规则设置互相矛盾的显示开关。

修改名称后，后续记录按新名称保存；已有数据库记录不会自动改名，短期内可能同时看到旧名和新名。设置进程规则也不能保证识别所有受保护进程，权限不足时可能回退窗口标题。

## 刷新与保存的特殊情况

- 配色、置顶、窗口大小、每格秒数、统计刷新和千问闲置时间：保存后刷新生效。
- 倒计时：还没开始时直接更新；运行/暂停中保留剩余时长，重置后用新时长。
- 软件名称和匹配规则：影响之后的识别与记录，不批量重写历史数据。
- 正常退出只更新窗口坐标，保留其他配置、未知字段和注释。
- 首次升级旧格式配置时保留原值，补注释与缺项，并可能创建 `config.txt.before_config_upgrade.bak`。
- 已经存在的进程规则不会被默认模板覆盖；后续启动也不会反复恢复用户主动删除的进程节。

本版本配置格式是项目自己的文本格式。请勿把 YAML、JSON 或一般 INI 的插值写法直接粘贴进来。
